# 创作阅读助手 - 移动端功能清单

> 生成时间：2026-07-09
> 版本：v0.1.24
> 技术栈：React 18 + TypeScript + Capacitor 6 + epubjs + SQLite

---

## 一、应用框架

### 1.1 导航系统
- 底部 Tab 导航：首页 / 书架 / 灵感 / 统计 / 我的（5 Tab）
- 页面间导航状态保持

### 1.2 全局功能
- **Toast 消息**：4.2s 自动消失，全局统一提示
- **应用主题**：浅色 / 深色 / 跟随系统
- **Android 硬件返回键**：8 级优先级处理，250ms 防抖，双击退出
- **确认对话框**：全局 confirmDialog 组件
- **QR 扫码**：扫码配对 + 错误提示叠加层
- **文件导入**：文件名/大小校验 → 编码检测 → 创建书籍 → 正文缓存（最大 80MB）
- **阅读器加载**：预览/缓存 → 异步全文加载（12s 超时）+ 历史栈
- **局域网同步**：配对/双向同步/正文下载/上传

## 二、阅读器

### 2.1 核心模型
- 5 个侧面板 Tab：目录 / 搜索 / 书签 / 笔记 / 灵感
- 5 种底部弹出类型：目录抽屉 / 设置面板 / 主题面板 / 进度气泡 / 灵感记录
- 6 阶段生命周期：idle → opening → preview → loadingFullContent → ready → error
- 7 种错误码：missing_content / empty_content / parse_failed / read_failed / read_timeout / not_downloaded / unsupported_format
- 默认设置：18px 字号 / 1.85 行距 / 22px 边距 / 暖纸背景 / 分页模式

### 2.2 阅读模式
- 横向分页模式（paged）：scroll-snap-type: x proximity + touch-action: pinch-zoom
- 上下滚动模式（scroll）：overflow-y: auto + 滚动到边界 Toast 提示
- 双模式切换 + 进度自动转换

### 2.3 格式支持

| 格式 | 渲染引擎 | 特性 |
|------|----------|------|
| TXT | 正则分章 + 段落渲染 | 编码检测（BOM→UTF-8→GBK→GB18030→Big5）、虚拟章节（14K 字符阈值）、全文章节渲染（300 章/5MB 上限） |
| Markdown | 自定义解析器 | 标题/代码块/表格/列表/引用/粗体/斜体/链接/图片 |
| EPUB | epubjs + iframe | CFI 定位、NCX/Navigation 目录解析、spine 匹配、内部链接跳转、默认跳过图片内联以保证稳定性（可按需开启 2MB 内联限制）、非可读项过滤 |

### 2.4 阅读导航
- 章节跳转（前后翻页 / 跳转指定章节 / 进度百分比跳转）
- 分页模式：scroll-snap 整页对齐，pageStep 从实际 CSS columnWidth + columnGap 计算，避免半页夹缝
- 滚动模式：smooth 滚动
- renderAll 模式：全章节渲染（进度转换使用 localProgress 直接作为全书进度）
- 视口恢复（双帧 RAF）
- 当前章节定位（基于 scrollLeft/scrollTop 或字符偏移）
- 阅读位置构建（text-anchor + page + scroll）

### 2.5 阅读设置
- **4 种背景色**：白纸 / 暖纸 / 护眼 / 夜间
- **字号调节**：A-/A+ 按钮 + 滑块（15-28px）
- **行距调节**：紧凑/标准/宽松 三档
- **段间距调节**：紧凑/标准/宽松 三档
- **亮度调节**：45%-100% 滑块
- **常亮显示**：Wake Lock API，关闭时自动释放
- **外观主题**：4 种背景色网格选择

### 2.6 标注系统
- **书签**：当前阅读位置一键添加，记录章节标题和进度百分比
- **笔记**：选中文字 + 手动输入，关联章节和进度
- **灵感记录**：打开灵感面板（标题/正文/分类/标签/来源自动记录）
- **搜索**：全文搜索，不区分大小写，最多 80 条结果，前后 28/42 字符上下文
- **复制选中文字**
- **清除选中**

### 2.7 触摸手势
- 横向滑动翻页（仅 paged 模式）
- 捏合缩放字号（12-36px）
- 五分区点击：左/右翻页，中上/中下/中央显隐菜单
- 滚动模式禁止左右滑动触发翻页

### 2.8 阅读统计
- 活跃时长计时（1s 心跳 + 45s 空闲阈值）
- 切换书籍自动重置计时器
- 进度自动保存（900ms 防抖）
- 阅读速度实时计算

### 2.9 底部菜单
- 5 按钮布局：目录 / 进度 / 灵感 / 主题 / 设置
- 进度气泡：统计行（本次时长/累计时长/字数/章节/灵感/书签）+ 进度条（24px）+ 章节跳转按钮（32px）
- 目录抽屉：层级树 + 当前章节高亮 + 阅读位置显示
- 主题面板：4 色背景 + 字号 A-/A+
- 设置面板：阅读模式 + 排版设置 + 外观主题 + 辅助功能

### 2.10 顶栏
- 返回按钮（保存进度）
- 书籍标题
- 阅读进度百分比
- 选中文字操作栏（复制/搜索/灵感/笔记/书签）

### 2.11 进度系统
- 进度保存：分页模式保存 pageIndex；滚动模式保存 scrollTop 百分比
- 进度显示：统一格式"第X章·第X页·X%"
- 进度冲突解决：CFI > text-anchor > page > scroll 精度优先级
- 阅读完成阈值：0.995，进度下降时重置完成状态
- 进度条集成在底部菜单中
