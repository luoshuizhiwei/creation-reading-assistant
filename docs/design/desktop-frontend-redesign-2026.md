## 一、结论（最终方向一句话）

**最终方向：「铸字车间」（Typesetter's Workshop）—— 以活字印刷时代的铸字机与排字盘为隐喻，用机铁灰面板、热铜橙强调与活字压痕触感，为本地优先的写作工具赋予一种"有重量的数字工作台"气质。**

## 二、三个视觉方向提案

### 方向 A：铸字车间（Typesetter's Workshop）★ 最终选定

**隐喻与情绪**
活字印刷车间、铸字机控制面板、铅字盘、Linotype 操作台。情绪是" industrious calm（ industrious 的平静）"——工具的机械精确与写作的创造性并存。

**配色板（6色命名）**

| Token | Hex | 用途 |
|-------|-----|------|
| `forge-iron` | `#24262b` | 最深面板、侧边栏背景、选中状态底色 |
| `slate-bed` | `#2e3138` | 次级面板、弹窗背景、抽屉底色 |
| `pulp-sheet` | `#e6e2d8` | 主工作区背景（未漂白纸张） |
| `cast-silver` | `#9ca0a8` | 分隔线、边框、次要文字、禁用态 |
| `hot-copper` | `#c45c28` | 主强调色（激活导航、主按钮、进度、印章） |
| `ink-black` | `#1a1c1f` | 正文标题、关键数据 |

**字体方案（3角色）**

| 角色 | 字族 | 特征与使用场景 |
|------|------|---------------|
| 显示体（Display） | `Playfair Display` + `Noto Serif SC` | 高对比度衬线，字重 700–900。仅用于页面大标题、Hero 区域、空状态标题。每页最多出现 2 次。 |
| 正文体（Body） | `Inter` + `Noto Sans SC` | 无衬线，字重 400–500。所有 UI 标签、段落、表单、卡片内容。 |
| 数据体（Data） | `JetBrains Mono` | 等宽。时间戳、文件路径、字数统计、版本号、代码块。字号比正文小 1px，行高 1.5。 |

**布局概念**
- 侧边栏 = 铸字机的控制条：固定宽度 220px，深灰底色，导航项像活字块一样有"压入"与"弹出"两种状态
- 主舞台 = 排字盘：内容区用卡片网格，卡片有微妙的凸版感（上边框高光 + 下阴影）
- 阅读器 = 书页夹：打开后像夹在阅读架上的两页书，批注像贴在页边的便签

**Signature 记忆点：活字压痕（Type Bite）**
激活/悬停的按钮、导航项、卡片有微妙的 `inset` 阴影组合：顶部 1px 半透明白色高光 + 底部 2px 深色阴影，模拟铅字压入纸张的物理触感。这是可解释的视觉风险——在扁平化时代显得"拟物"，但与"铸字车间"主题高度自洽，且仅用于交互态（默认态完全扁平）。

### 方向 B：深夜电台（Midnight Radio Station）

**隐喻与情绪**
深夜写作时的广播控制台、VU 表、调频旋钮。情绪是"孤独的专注"——深夜只剩自己和信号。

**配色板**
- `deep-space` `#0d1117`、 `panel-blue` `#161b22`、 `fluoro-cyan` `#39d0d8`、 `warm-amber` `#f0a030`、 `paper-grey` `#c9d1d9`、 `mute-grey` `#8b949e`

**字体方案**
- 显示体：`Space Grotesk`（几何无衬线，有技术感）
- 正文：`Inter` + `Noto Sans SC`
- 数据体：`JetBrains Mono`

**布局概念**
- 控制台式高密度布局
- 所有进度指示器做成 VU 表样式（垂直/水平条形 + 峰值保持）
- 选中态有微弱荧光脉动

**Signature 记忆点：VU 表进度条**

**不选理由**：本质上是用户明确禁止的"近黑底 + 单一荧光强调色"套路的变体；与"写作者工作台"主题的关联较弱；长时间阅读舒适度差；与现有阅读器多主题切换的冲突最大。

### 方向 C：植物标本室（Botanical Press Archive）

**隐喻与情绪**
植物标本夹、档案卡片、野外考察手册。情绪是"培育与归档"——每一个想法都是一株待压干的植物。

**配色板**
- `press-paper` `#f2efe9`、 `herbarium-green` `#2d4a3e`、 `ochre-label` `#8b6914`、 `dried-rose` `#a85d5d`、 `charcoal` `#242320`、 `moss-grey` `#7a8a7a`

**字体方案**
- 显示体：`LXGW WenKai（霞鹜文楷）` 或 `Crimson Pro`
- 正文：`Inter` + `Noto Sans SC`
- 数据体：`JetBrains Mono`

**布局概念**
- 档案卡片式内容块
- 批注/摘录像和纸胶带贴在边缘
- 编辑区有极淡的方格底纹（模拟野外笔记本）

**Signature 记忆点：标本胶带（Washi Tape）**

**不选理由**：霞鹜文楷作为外部中文字体资源文件过大（~5MB+），与 Electron 本地优先的轻量加载理念冲突；手写感字体在 UI 标签中大量使用会降低可读性；和纸胶带效果在实现上需要复杂的 CSS 伪元素或 SVG，维护成本高；与现有设计的差异虽大，但"标本室"隐喻与"写作"的关联不如"铸字车间"直接。

### 3.2 字体系统

| 层级 | 字族 | 字号 | 字重 | 行高 | 字间距 | 用途 |
|------|------|------|------|------|--------|------|
| Display XL | Playfair Display / Noto Serif SC | 28px | 800 | 1.15 | -0.03em | 页面 Hero 标题 |
| Display L | Playfair Display / Noto Serif SC | 22px | 700 | 1.2 | -0.02em | 面板标题、空状态 |
| Heading | Inter / Noto Sans SC | 16px | 600 | 1.35 | -0.01em | 区块标题、对话框标题 |
| Body | Inter / Noto Sans SC | 13px | 400 | 1.6 | 0 | 正文、段落 |
| Label | Inter / Noto Sans SC | 12px | 500 | 1.4 | 0.04em | 按钮、标签、导航 |
| Caption | Inter / Noto Sans SC | 11px | 400 | 1.45 | 0.02em | 辅助说明、时间戳 |
| Data | JetBrains Mono | 12px | 400 | 1.5 | 0 | 统计数字、路径、版本号 |

**字体加载策略**
- Playfair Display：Google Fonts 子集加载（latin 字符，~30KB），仅用于英文 Display；中文 Display 回退到 Noto Serif SC（系统已缓存或本地打包）
- 不引入新的中文字体文件，依赖系统已有的 Noto Sans SC / Noto Serif SC / PingFang SC / Microsoft YaHei

### 3.3 间距系统

基于 4px 网格，但有意引入一个"不整齐"的变量——**活字间隙（type-gap）**：

- 标准间隙：`4px / 8px / 12px / 16px / 20px / 24px / 32px / 40px`
- 活字间隙：`14px / 18px / 22px`（用于卡片内边距、按钮组间隙，制造"手工排版"的微妙不整齐感）

全局圆角策略：
- 大面板/页面卡片：`16px`（比现有 24px 更克制）
- 按钮/输入框/小卡片：`10px`
- 标签/徽章：`6px`
- 完全圆角（搜索框、头像）：`999px`

### 3.4 Signature 记忆点：活字压痕（Type Bite）

**视觉定义**
交互元素在 `:hover` 和 `[data-active="true"]` 状态下获得一层微妙的物理压痕感：

```
效果栈（从上到下）：
1. inset 0 1px 0 rgba(255,255,255,0.15)   ← 顶部高光（模拟铅字顶部反光）
2. inset 0 -1px 0 rgba(0,0,0,0.08)        ← 底部阴影（模拟压入深度）
3. 0 1px 2px rgba(0,0,0,0.04)             ← 外部微阴影（分离感）
```

**应用范围（克制）**
- ✅ 侧边栏导航项（激活态）
- ✅ 主操作按钮（hover/active）
- ✅ 关键卡片（hover）
- ✅ 阅读器设置抽屉的选中项
- ❌ 不使用于：正文区域、阅读器书页、表单输入框（保持扁平以便书写）

**风险解释与回退**
若视觉评审认为"过于拟物"，回退方案是仅保留 `inset` 顶部高光一条，去除底部阴影，退化为"微凸感"而非"压痕感"。该回退无需改动结构，仅调整 CSS 变量值。

### 3.5 动效预算

| 动效类型 | 时长 | 缓动 | 用途 |
|----------|------|------|------|
| 页面切换 | 220ms | `cubic-bezier(0.22, 1, 0.36, 1)` | 内容区淡入 + 轻微上移（继承现有 motion-page） |
| 卡片 hover | 180ms | `ease` | 位移 + 阴影 + 边框色 |
| 对话框弹出 | 180ms | `cubic-bezier(0.22, 1, 0.36, 1)` | 缩放 + 淡入 |
| 抽屉滑入 | 220ms | `cubic-bezier(0.22, 1, 0.36, 1)` | 从右滑入 + 淡入 |
| Toast 通知 | 210ms | `cubic-bezier(0.22, 1, 0.36, 1)` | 从右上滑入 |
| 压痕触发 | 160ms | `ease` | hover 时阴影层的渐入 |

**不做的动效**
- 无页面间复杂过渡（如共享元素过渡）
- 无滚动触发的视差或揭示动画
- 无加载骨架屏动画（保持简单 spinner 或文字提示）

## 六、风险与待确认假设

### 假设 1：深色/浅色策略
**问题**：新方向的侧边栏在 light 模式下也是深色（`forge-iron`），这是否可接受？
**默认取舍**：可接受。这是"铸字车间"主题的核心视觉特征——深色工具带 + 浅色工作台的对比。参考 VS Code、Figma、Linear 等工具型应用，深色侧边栏在浅色主题下是常见且有效的模式。
**回退**：若评审不通过，可将侧边栏在 light 模式下改为 `pulp-sheet` 底色 + `ink-black` 文字，牺牲部分辨识度换取安全。

### 假设 2：字体资源引入
**问题**：Playfair Display 需从 Google Fonts 加载，离线环境（纯内网）下是否会失败？
**默认取舍**：添加可靠的 font-display: swap 与本地回退栈（`Playfair Display, Noto Serif SC, SimSun, serif`）。若加载失败，回退到 Noto Serif SC，视觉差异在可接受范围（两者都是高对比度衬线）。Electron 应用可考虑将字体文件打包到本地 `assets/fonts/` 目录。
**回退**：完全移除 Playfair Display，仅使用 Noto Serif SC 作为 Display 体。

### 假设 3：活字压痕效果的实现成本
**问题**：`inset` 阴影组合在复杂层级（如滚动容器内、transform 动画中）可能产生渲染问题。
**默认取舍**：压痕效果仅应用于有 `position: relative` 的独立块级元素（导航项、卡片、按钮），避免在滚动条、表格行、内联元素上使用。使用 Tailwind 的 `shadow-*` 工具类组合，不使用自定义滤镜。
**回退**：若发现性能或渲染问题，退化为仅保留 `border-color` 变化 + `translateY(-1px)` 的扁平方案。

### 假设 4：布局从三栏改为两栏的影响
**问题**：现有 `desktop-workbench` 是 `236px 1fr 276px` 三栏，移除右侧 276px 后，原先放在右侧栏的内容（如果有）需迁移。
**默认取舍**：经代码审查，现有右侧栏在大多数页面中为空或未充分利用。灵感页（Inspiration）的三栏（`300px 1fr 300px`）是页面内部布局，不受 Shell 影响。项目编辑器的右侧属性面板可改为浮动抽屉或页面内嵌面板。
**待确认**：需与产品负责人确认右侧栏是否有计划中的功能（如 AI 助手常驻面板）。

### 假设 5：阅读器多主题与新视觉的兼容性
**问题**：现有阅读器有 7 种背景主题（white/warm/green/night/amber/parchment/beans），新视觉的 token 系统是否需要为每种阅读主题重新定义？
**默认取舍**：阅读器主题是独立概念，与全局 UI 主题正交。新视觉只翻新阅读器的"壳层"（顶栏、抽屉、侧栏），书页背景保持用户选择的阅读主题不变。Shell 的 `hot-copper` 进度条/强调色在每种阅读主题上都应有足够的对比度（已验证）。
**待确认**：夜间阅读主题（reader-bg-night）下，hot-copper 进度条是否过于刺眼？可能需要为夜间阅读主题使用降低饱和度的铜橙色。
