## 1. 设计原则（移动原生，非网页）

1. **固定竖屏容器**：内容宽度受 `min(100%, 560px)` 约束（现有 `.phone-page`），不做横向流式布局。
2. **触控优先**：所有可点目标 ≥ 44×44px（现有 `.round-action`/`.ghost-button` 已遵守）；反馈用 `:active` 缩放，不用 `:hover` 主色（现有已用 `@media (hover: hover)` 隔离）。
3. **安全区适配**：所有贴边用 `env(safe-area-inset-*)`（现有 `.mobile-shell` 已做）。
4. **原生导航范式**：底部 5 标签固定导航 + 顶部 AppBar + 底部 Sheet，不出现浏览器式地址栏/返回箭头文字。
5. **内容优先于 chrome**：装饰（光晕、渐变）只做氛围，不抢内容；卡片用柔影而非硬描边。

## 3. 分类色封面规范（核心新增）

**目的**：书架从"统一铜色"升级为"按分类辨识"，每张封面自带标题 + 进度/状态角标，呼应原型"封面即信息"的思路（原型本身只有单色，这里做进一步增强）。

**数据结构**（书模型建议加 `category` 字段）：
```ts
type BookCategory = 'literature' | 'social' | 'tech' | 'history' | 'art' | 'default';
```

**封面结构（CSS）**：
```css
.book-cover {
  position: relative;
  aspect-ratio: 0.72;                 /* [现有] */
  border-radius: var(--app-control-radius);
  background: var(--cover-default);   /* [新增] 默认梯度 */
  color: #fff6ef;
  padding: 12px;
  display: flex; align-items: flex-end;
  box-shadow: var(--app-soft-shadow);
  overflow: hidden;
}
/* 分类映射（用属性选择器，零 JS 成本） */
.book-cover[data-category="literature"] { background: var(--cover-literature); }
.book-cover[data-category="social"]     { background: var(--cover-social); }
.book-cover[data-category="tech"]       { background: var(--cover-tech); }
.book-cover[data-category="history"]    { background: var(--cover-history); }
.book-cover[data-category="art"]        { background: var(--cover-art); }

/* 封面内进度条（右下角标） */
.book-cover .cover-progress {
  position: absolute; left: 12px; right: 12px; bottom: 12px;
  height: 6px; border-radius: 999px;
  background: rgba(255,255,255,.28);
  overflow: hidden;
}
.book-cover .cover-progress > i {
  display: block; height: 100%;
  background: rgba(255,255,255,.92);   /* 浅色封面用白进度，对比清晰 */
}
```

**深色模式**：封面保持彩色梯度即可（实体色不随 dark 反白），仅需把 `--cover-default` 在 dark 下切到 `--cover-default-dark` 降低明度，避免刺眼。

## 4. 组件规范

每个组件：现状 → 蓝图 → 关键片段。

### 4.1 AppBar（顶部栏）[现有 `.mobile-header`]
- **现状**：`.mobile-header h1` 用 headline-large(32) weight 600。
- **蓝图**：大标题改 `--font-display` + **700** + 30px；上方加 eyebrow 小标（如「今日 · 7月20日」）；右侧可放图标按钮（lucide）。
- **片段**：
```css
.appbar-title {
  font-family: var(--font-display);
  font-size: 30px; font-weight: 700; line-height: 1.16;
  letter-spacing: -0.01em;
}
.appbar-eyebrow {
  color: var(--md3-primary);
  font-size: 12px; font-weight: 500; letter-spacing: .08em;
}
```

### 4.2 状态胶囊 [现有 `.status-chip` → 升级]
- **现状**：`.status-chip` 已有 hairline 边框 + 16px 圆角 + color-mix active（release-overrides 305–338）。
- **蓝图**：提升为一级规范；补充语义色变体（reading=warning 容器 / done=success 容器 / streak=streak 容器）；圆角统一到 `--app-control-radius`(18)。
- **片段**：
```css
.status-chip {
  min-height: 54px; padding: 10px 12px;
  border: 1px solid var(--app-hairline);
  border-radius: var(--app-control-radius);
  background: rgba(255,252,246,.72);
}
.status-chip[data-tone="done"]   { background: var(--md3-success-container); }
.status-chip[data-tone="reading"]{ background: var(--md3-warning-container); }
.status-chip[data-tone="streak"] { background: color-mix(in srgb, var(--md3-streak) 14%, #fff); }
```

### 4.3 卡片 [现有 `.metric-card` 等 → 统一]
- **蓝图**：所有门面卡片用 `--app-card-radius`(22) + `--app-soft-shadow-sm` + 可选玻璃（`backdrop-filter: blur(12px)` + `rgba(255,253,250,.88)`）。
- **片段**：见 §2.4 阴影；玻璃见原型 `.cra-card`。

### 4.4 列表行（book-row / menu-row）
- **现状**：分散在各页，圆角不一。
- **蓝图**：统一 `--app-control-radius`(18) + hairline 分隔 + `:active` 轻微底色；行高触控 ≥48px。

### 4.5 底部导航 [现有 `.bottom-nav` → 毛玻璃增强]
- **现状**：固定实色 `--md3-surface-container`，active 用 `::before` 胶囊背景 + 图标 scale(1.05)，已是标准范式。
- **蓝图**：背景改毛玻璃（原型 `.cra-bottom-nav` 的 `blur(16px)`），提升层次；其余保持。
- **片段**：
```css
.bottom-nav {
  background: color-mix(in srgb, var(--md3-surface-container) 82%, transparent);
  -webkit-backdrop-filter: blur(16px);
  backdrop-filter: blur(16px);
}
```

### 4.6 底部 Sheet [现有]
- **蓝图**：圆角 `--app-sheet-radius`(24) + 顶部抓手条（handle）+ 从底部滑入（现有有 transition，补 `translateY` 进入）；背景毛玻璃。

### 4.7 FAB [现有 `.inspiration-fab`]
- **蓝图**：保持 56px + `--app-control-radius`(18) + `--app-glow`；`:active` scale(.95)。

### 4.8 进度条 [新增令牌化]
- **蓝图**：统一铜渐变，7px 高通栏：
```css
.progress-track { height: 7px; border-radius: 999px; background: rgba(154,98,48,.12); overflow: hidden; }
.progress-fill  { height: 100%; border-radius: inherit; background: linear-gradient(90deg, #bb8655, #7a4923); }
```

### 4.9 空态 [新增组件]
- **蓝图**：中线插画（SVG 线条风，暖铜色）+ 一句手写体引导文案 + 主按钮。避免"空白+灰字"的网页感。

### 4.10 阅读器正文 [现有 MobileReaderView]
- **蓝图**：走纸感——`line-height: 1.95`、`text-indent: 2em`、正文色 `#2f241c`、背景 `--app-page-bg` + `--app-ambient`；底部 pill 工具栏（lucide 图标 + 文字标签）。

### 4.11 Chip / 标签 [新增]
- **蓝图**：横向滚动 chip 行，选中态用 `--md3-primary-soft` 底色：
```css

.chip.active { background: var(--md3-primary-container); color: var(--md3-on-primary-container); }
```

## 6. 去网页感反模式清单（防回归）

改造时**禁止**出现，CI 可做 lint 校验：
1. 字符箭头 `‹ › ← →` 作 UI 文案 → 用 lucide 图标（已清理，见 2026-07-20 日志）
2. `min-width: 320px` 之类小屏响应式收口 → 真机 WebView 本就手机宽（已清理）
3. `:hover` 作主色反馈且不隔离 → 必须 `@media (hover:hover) and (pointer:fine)` 包裹
4. 硬边 `box-shadow: 0 0 0 1px #000` 描边 → 用柔影/ hairline
5. 过宽容器（`max-width > 560px`）→ 守 `--phone-page`
6. 文本「← 返回」→ 图标按钮 + 文案「返回」
7. 长设置列表无分组 → 用卡片分组（`.settings-card` 已有）

## 8. 验收标准

- ✅ 全站 0 字符箭头、0 网页响应式收口（§6）

- ✅ 对比度达 WCAG 2.1 AA（正文 `#221915` on `#fffaf1` 已达标）
