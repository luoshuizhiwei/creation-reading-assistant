## 四、优先级建议(按影响 × 紧急度)

**第一优先(直接影响阅读体验,样式优化时一并修)**:
- P1 书架列表虚拟化 + P2/P3 阅读器重渲染与滚动节流 + P7 阅读器退出停 TTS + G3 阅读中开灵感丢会话

**第二优先(数据安全,样式优化前修)**:
- F1 首屏加载加 .catch + F2 同步按 id 合并 + G2 删书 try/catch + G1 删分类清灵感引用

**第三优先(兼容性,样式优化时一并修)**:
- C1 color-mix 加 fallback + C2 backdrop-filter 加 fallback + C3 Filesystem 平台判断

**第四优先(性能基建)**:
- F3/Q4/P4 saveMobileSnapshot 增量化 + SQLite 批量事务 + JSON offload worker
- P5 epubjs/jsqr 动态 import

**第五优先(可维护性,后续重构)**:
- Q1/Q2/Q3 巨型组件拆分 + Q5-Q9 重复代码抽取 + Q13 魔法数字常量化
