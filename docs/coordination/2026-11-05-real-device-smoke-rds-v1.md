## 零接触模式（用户 2026-11-05 明确指示）

**用户本批全程不碰手机。** 每一个需要设备交互的环节（权限弹窗、系统确认、SAF 文件选择器、安装确认、按键、UI 导航）必须由执行者自行解决：`adb shell input tap/swipe/keyevent`、uiautomator dump 定位、项目现成脚本。**禁止因"需要人点一下"而停止或转问用户**——只有本合同停止条件（数据安全类）才允许停。

- 安装确认：MIUI"USB 安装"确认弹窗用仓库现成脚本 `android/scripts/tap_usb_install_confirm.py`（已随 archive commit `c7d8671` 入库；诊断辅助 `diag_usb_confirm.py`）自动点击；若弹窗被小米账号登录门槛挡住（脚本无法越过）→ 停止并报告，这属于环境门不是可模拟交互。
- 音量键：`adb shell input keyevent KEYCODE_VOLUME_UP/DOWN` 视为本批等效真机按键测试。
- 拔耳机暂停（P8）：无法脚本模拟，记 `NOT_RUN`（注明原因），不算失败；若设备连有蓝牙耳机且可脚本断连则尝试。
- 锁屏：测试开始时确认屏幕已解锁；若中途锁屏且无 PIN 可通过 adb 绕过 → 用 wake + 滑动尝试，仍不行则停该项改做下一项，最后汇总时列为 BLOCKED 设备状态项。
- 保持唤醒：启用 `settings put global stay_on_while_plugged_in 3`（P0.3 记录原值，P13 恢复），充电线全程保持连接。
