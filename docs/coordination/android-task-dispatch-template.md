# 原生Android任务派发模板

开工前由Root或用户指定的接任协调者落盘填写并核查，不把历史路径或权限直接传给下一轮。先给总览表：编号/版本、时间、作用、推荐模型、真实并行/依赖、预计耗时；每个完整外部提示词放在一个至少四反引号代码框。模型选择不产生外部消息授权。

```text
任务编号/版本、当前日期：
基线：活动current页首、直接相关报告、输入绝对路径与已接收SHA；不扫全部历史。
目标与成功标准：完整功能链或明确修复；区分实现、离线、模拟器、整链。
所有权：独占可写文件/目录；其他执行者及禁止覆盖范围；公共接缝交Root。
依赖/并行：独立工作并行；公共集成、完整构建、同设备各唯一owner。
存储预算（派发前必填）：
  新增大目录及预计字节（没有写“无”）；现有唯一构建工作区；
  既有Gradle home/依赖路径；构建owner与独占锁；本轮报告/差量路径。
实施与交付：仅最小patch、改动源码、前后SHA、REPORT、必要原始日志/XML。
  不复制完整工程、build/.gradle/.kotlin/node_modules/Gradle home、历史证据、
  备份或APK对；不硬链接可写缓存。不因并行另建环境。
核验：输入、环境、验收范围未变且证据充分则引用原始日志/退出码/冻结。
  原严格PASS冻结可经scripts/android-reuse-freeze.py复核后原路径引用；
  SHA由Root已接收报告提供，保持原config与相对引用cwd。
  不为下一任务编号另wrap、不复制已冻结APK、不执行历史强制重建脚本。
  复用FAIL停止交Root，不自动fallback构建。确需构建只补受影响变体/门禁，
  使用现有唯一工作区和锁；新构建同SHA不证明未构建，保留原日志交合同接缝。
报告：在同一REPORT写实际新增字节及统计范围、保留理由；临时可再生成材料、
  必要交付、唯一证据、恢复资产分列。后两类不得当临时缓存处理。
停止条件：所有权冲突、预算/输入/冻结/恢复合同不明即停止依赖工作并报Root。
  既有资产不删除/移动/压缩/迁移；可回收项按精确子路径及后果另列待用户确认。
  设备、Git、发布、外部应用、自动化分别按本轮授权，不继承历史许可。
```

接续分支及不依赖原窗口的协调/核验方法见[接任执行手册](../handoff/continuation-playbook.md)，可填的[单任务执行单](../handoff/next-agent-start-template.md)供其他agent承接。每轮结束必须把下一步写入文档，报告可交用户/接任协调者，不等待原Root额度。

当前工作区/缓存/owner只维护于current页首，避免此模板再留一份过期路径。
