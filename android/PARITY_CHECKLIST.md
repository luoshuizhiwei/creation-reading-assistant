## 一、首页 Home（HomeScreen / HomeContinueSheet）

|------|--------|-----------|-----------|------|
| H1 | 累计阅读本数口径 | `readableBooks`（经 `isBookReadableOnDevice` 过滤）中已读数量 | 未过滤可读性，多计入 failed/missing 等 | 数据口径 |
| H2 | 卡片打开前 readiness 校验 | `getBookReadiness` 校验，不可读弹「暂时无法阅读」 | 直接 `navigate("reader/{id}")`，无拦截 | 交互/容错 |
| H3 | 最近灵感点击 | 打开**指定**灵感详情（带 id） | 仅跳到灵感列表页 | 导航精度 |

| H5 | 阅读统计分区标题 | 有 `<h2>阅读统计</h2>` | 无标题 | 文案 |
| H6 | 已读完排序键 | `completedAt ?? updatedAt` 降序 | `updated_at ?? updated_at` | 数据口径 |
| H7 | 继续阅读空状态文案 | 「书架还空着，先导入一本 TXT、Markdown 或 EPUB。」 | 字符串未对齐 | 文案 |

### 已知未完全对齐（已记录，非阻断）
- **阅读器定位精度**：原生高亮/笔记实体 `locator_json` 恒为 null（创建高亮未持久化 CFI/行内偏移），故 SE4/R4 仅能定位到**章节级**（按 chapter_title / progress_percent），无法像网页滚到章节内具体字符。后续若让阅读器写入 `locator_json` 即可升级为行内精确定位。
- **EPUB 逐句高亮**：R2 当前句高亮+滚动同步仅 TXT 实现，EPUB 仍为段落级。
- **灵感点击跳转**：H3 已实现按 id 打开灵感详情面板；但全局搜索中灵感结果点击当前跳到灵感列表页（非指定详情），原生缺 `inspiration/{id}` 路由（建议后续补）。
- **索引大小口径**：P4 `indexBytes = books.sumOf { size }` 与网页源码严格一致；但原生 `BookEntity.size` 仅在正文下载成功后写入，故数值接近「已下载正文总量」。
- **TTS 锁屏通知**：R1 已实现 MediaSession + MediaStyle；Android 13+ 需用户授权 `POST_NOTIFICATIONS` 才显示锁屏媒体通知（已在 Manifest 声明权限，运行时授权由系统弹窗处理）。
- **书架 S3 阅读记录**：按书聚合展示，未做网页的「日期」二次子分组（数据已具备，仅展示层级简化）。

> 全程未改动底部 5 Tab 导航骨架、未引入平行主题令牌、未重新设计 UI；阅读器背景/高亮硬编码色为 #61 阶段从网页 `reader-constants.ts` 对齐的精确值，属合法数据。
